# 4.1.0 高山远征与实测

测试环境：2026 年 11 月 18 日，Windows，Minecraft 1.21.1、NeoForge、Java 21，254 个锁定模组。使用隔离客户端，原启动器实例与原存档未参与写入。

拔刀剑：实际游戏的按键处理路径覆盖普通 Yamato 与神格拔刀剑的左键空挥、左键命中、右键六组场景。每组输入四次，均依次进入 `combo_a1 → combo_a2 → combo_a3 → combo_a4_ex`。持刀时 Epic Fight 切回原版战斗，第三人称可见出刀与刀光。

高山远征包含双站铁路、训练场与引导；轨道炮包含生物模式、地形模式、蓄力和冷却。两项的客户端验证结果随发布更新。
