# 高山铁路与战斗改造方案

用户已确认按本方案实施。

## 目标与已确认方向

用户选择：专属铁路起始区域连接外围随机大世界。写实风景、巨大山脉、宽广群系、清晰玩法主线与可反复游玩的成长系统并重。必须修正拔刀剑左键无法连击、动作互相覆盖的问题。新增双模式强力轨道炮，具备完整蓄能与命中表现。

## 路线取舍

- **已选择：定制起始区域＋随机世界。** 提供独立新存档，出生在铁路枢纽；远方继续自然生成。普通随机开档仍可选。
- 完整固定剧情地图：能严格编排景观与遭遇，但限制随机探索，不采用。
- 完全随机、玩家自行建设铁路：自由度高，但无法保证出生体验和初期目标，不作为默认体验。

## 地形与风景

用户提供的 `史诗地形数据包.zip` 保持原文件不变。内容包含 576 格维度、新版 attributes/timelines 字段，pack_format 却标为 15，需要按当前 Minecraft 1.21.1 检查和适配；不能只改版本号。

工程选择：先在独立测试世界对比该包适配结果与现有 Tectonic/Terralith 配置。仅选择一个主要地形生成来源，避免重叠覆盖噪声导致失真。优先保留自然山脊、河谷、石岸、雪线，减少浮空与过饱和奇幻景观。超大群系与提高山体尺度分别调节，并检查遗迹实际能生成、铁路坡度可用、探索不会被超大海洋阻断。

默认地图第一阶段提供原创起始站、维护工坊、训练场和一条可乘坐的山谷观景支线，至少两个有实际用途的站点。铁路的停靠、返程、列车加载与存档重开必须通过实测。不会把几段装饰轨道描述为完整运营铁路。远方铁路扩张成为玩家的长期项目。

起始区域以独立预生成存档交付，固定种子和生成配置；铁路外围一并预生成过渡带，验收边缘接缝。记录采样地表高度范围、连续群系跨度、区块生成耗时、测试硬件及内存；以同种子基线对比，不承诺未经测量的帧率。

## 清晰而开放的玩法

从现有六法则和二十四神物成长延伸，不再只靠七页手册。明确显示当前目标、材料来源、奖励和下一步：

1. 在起始站安顿：食物、床、操作训练与第一把拔刀剑。
2. 沿铁路远征：地图、补给、遗迹定位与第一个法则神物。
3. 建立工坊：机械加工、铁路建设和二阶武器。
4. 六系专精：让遗迹战斗、生产、农业、魔法各自有对应收益；允许自由切换。
5. 神格仪式与神域武装：成神、特殊刀谱、轨道炮。

任务应可自动检测的自动检测；纯教学明确标为阅读确认。可重新查看路线，不强制把所有模组锁进任务链。参考《落幕曲》的引导结构与战斗成长，不直接复制其他整合包文件。用户提到的《成神之路》尚未确定具体作者和版本。

首轮验收流程固定为：领取刀具 → 命中训练目标 → 乘车到第二站 → 收集首个神物所需材料并取得神物 → 返回起始站。以物品/位置/攻击实际记录判断；重登保留进度，丢失教学物品有补领入口，非唯一材料可重复获取。

## 拔刀剑修复验收

分别检查左键空挥、左键命中、右键连击、切刀立即攻击、战斗模式切换、第一/第三人称和锁定目标。记录真实鼠标输入与服务端连击状态。定位冲突来源后处理负责输入/动画的层；若 Epic Fight 无法稳定共存，按用户此前允许的方案移除冲突动作系统及确实只依赖它的附属。保留拔刀剑自身动画与独立技能键。

## 轨道炮提案（参数由实现方建议，待确认）

- 成神后解锁的手持瞄准器，以准星指定落点，按住右键 3 秒自动发射，提前松手取消；独立模式切换键与 HUD 显示当前模式、蓄能和冷却。
- **歼灭模式**：清除落点一定范围内的非玩家生物，包含动物，不改方块。默认不攻击玩家及玩家驯服的宠物。以实际实体死亡和掉落验证，不只做视觉爆炸。
- **地形模式**：清除落点区域方块和生物，形成明显弹坑；地形清除按批次推进，避免一帧执行大体积填充。尊重地图边界、未加载区块和领地权限。
- 初版建议：瞄准距离 128 格；歼灭半径 24 格；地形弹坑半径 16 格、深 24 格；蓄能 3 秒、冷却 30 秒。数值集中配置，之后可提升，不把无限范围作为默认。
- 动画分段：准星锁定与地面范围标记 → 环形蓄能与声调上升 → 天空聚光 → 主束贯穿 → 冲击环、余辉、扬尘。粒子有数量预算，镜头震动可关闭。
- 模式切换不立即开火，切换、松手取消和冷却反馈必须清晰。关界面、换物品、死亡、离线应取消蓄能。

两种模式共享玩家与宠物保护；对普通生物与 Boss 走正常死亡流程，神格玩家保持既有免疫规则。对第三方特殊无敌机制逐项实测，不声称无条件秒杀所有实体。起始站核心和领地保护区域不参与地形清除，准星显示受保护状态。无落点、落点区块未加载时不发射；服务端核验持有物、成神资格、模式、目标距离和冷却。箱子等方块实体默认受保护，破坏模式不批量产生方块掉落；队列有单帧预算和总量上限，存档退出取消未完成队列，重进不会重复执行已完成部分。
