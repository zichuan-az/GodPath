# 远征日志

在聊天框输入 `/journey` 查看当前目标。首次进入世界时也可点击聊天中的入口。点选「六法则与仪式」或执行 `/journey laws`，可以查看各法则已共鸣数量、尚缺神物和材料来源。

## 高山铁路开局

1. 在枢纽站用 `/journey blade` 领取木制拔刀剑。练习时将刀放在主手，到站南 X=12、Z=20 的训练场命中训练靶 3 次。遗失或损坏后，携带一把木剑和两块原木回枢纽站补领。也可自行用相同材料合成。
2. 在枢纽站登上矿车，按车站发车按钮，坐到东端松脊前哨。日志记录完整的矿车行程。
3. 到松脊前哨内 X=183、Z=-7 的补给箱收集样品，在工作台无序合成世界种子（原初碎片 ×4、橡树树苗 ×2、紫水晶碎片 ×1）。备份材料可挖深板岩、凝灰岩和成熟紫水晶簇，砍橡树等树叶掉落树苗。深板岩 ×8 和钻石 ×1 也能合成原初碎片 ×1。
4. 世界种子入背包后，坐矿车回西端枢纽站。可以发展 Create 工坊、建设自己的铁路，继续做六系刀谱和神物。

## 普通随机开档

`/journey` 指向食物、床和第一件神物。世界种子可按同一配方合成，也可以从任意其他神物开始，随后查看六法则。木制拔刀剑原版模组配方是在工作台左下放木剑、正中和右上各放一块原木。

## 六法则与成神

用探索者罗盘寻找对应遗迹，用 JEI 查看合成配方。一阶神物先放在背包或佩戴片刻，收到共鸣提示后再消耗它合成二阶。共鸣 24 件后右键磁石进行仪式，获得万象神裁并解锁轨道炮的使用资格。可在 JEI 查看轨道炮配方，在控制设置里查看模式键。
