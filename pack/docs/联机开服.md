# 联机开服 · 32 人

## 一、最快路线

1. 复制一份 `manual/` 里的全部内容到服务端文件夹
2. 从 PCL2 的整合包实例里复制 `mods/` 过来（**必须与客户端一致**）
3. 放上 `server.properties`（本包已提供）
4. 用 NeoForge 21.1.250 的 `run.bat` / `java -jar` 启动

一键启动脚本（Windows，保存为 `start.bat`）：

```bat
@echo off
set JAVA=java
set MEM=8G
%JAVA% -Xms%MEM% -Xmx%MEM% -XX:+UseG1GC -XX:+ParallelRefProcEnabled ^
 -XX:MaxGCPauseMillis=130 -XX:+UnlockExperimentalVMOptions -XX:+DisableExplicitGC ^
 -XX:+AlwaysPreTouch -XX:G1NewSizePercent=28 -XX:G1MaxNewSizePercent=45 ^
 -XX:G1HeapRegionSize=8M -XX:G1ReservePercent=18 -XX:InitiatingHeapOccupancyPercent=22 ^
 -jar neoforge-21.1.250-server.jar nogui
pause
```

> 服务端 jar 由 NeoForge 安装器生成；PCL2 也能一键装服务端。

## 二、端口

| 用途 | 端口 | 协议 |
|---|---|---|
| Minecraft | 25565 | TCP |
| 简单语音（Simple Voice Chat） | 24454 | **UDP** |
| 查询/状态 | 25565 | TCP |

语音不通用时，90% 是**没放行 UDP 24454**。

## 三、客户端与服务端必须一致的东西

| 项 | 要求 |
|---|---|
| mods/ | **完全一致**（版本号也要一致，`.mrpack` 导出的就是同一套） |
| 1.21.1 + NeoForge 21.1.250 | 一致 |
| `server.properties` | 只在服务端 |
| `kubejs/` | **两边都要有**（客户端需要贴图与语言） |
| `config/` | 服务端优先，客户端可有本地渲染配置差异 |

## 四、联机体验配置

### 领地（Open Parties and Claims）
- 客户端按 `O` 打开
- 圈地后默认防爆、防拆、防 PVP
- 建议：每个人 2~3 个领地，公共区域（出生点）单独设一个队伍领地

### 语音（Simple Voice Chat）
- 客户端按 `V` 说话（默认按键）
- 支持 3D 距离衰减、分组频道
- 服务端配置：`config/voicechat/voicechat-server.properties`
  - `port=24454`
  - `max_voice_distance=48`
  - `allow_groups=true`

### 传送石（Waystones）
- 放在村庄里，玩家自己也能合成
- 跨维度传送默认开
- 建议在出生点放一个"公共传送枢纽"

## 五、32 人 TPS 保底

| 措施 | 说明 |
|---|---|
| `view-distance=10` / `simulation-distance=8` | 已写进 server.properties |
| 预生成 | `/chunky radius 2000` → `/chunky start`，开服前跑完 |
| 限制 Create 列车数量 | 每列车 ≤ 12 节车厢，超过会明显掉 TPS |
| AE2 分区 | 大网络拆成 2~3 个独立网络，避免单网络 tick 过重 |
| 禁止高频红石 | `/gamerule randomTickSpeed 3`（默认） |
| 定期清理 | `/kill @e[type=item]`（掉落物）；`/forge tps` 看负载 |

## 六、常见联机问题

| 现象 | 处理 |
|---|---|
| 进服卡在"正在加入世界" | 客户端 mods 与服务端不一致，看日志第一条 mismatch |
| 语音没声音 | UDP 24454 未放行 / 客户端未授权麦克风 |
| 领地不生效 | 服务端装 `open-parties-and-claims`，客户端也要 |
| 有人能飞，有人不能 | 飞行靠 KubeJS 脚本，**服务端**必须装 kubejs 与脚本 |
| 神物进度丢 | 进度存在玩家 NBT（`gp_found`），换服要一起迁移 `playerdata` |
| 地形和别人不一样 | 世界种子 + `tectonic/terralith` 数据包必须一致 |
