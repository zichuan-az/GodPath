# 常见问题（FAQ）

## 装不上 / 启动崩

**Q：启动直接崩，日志写 `Mod loading has failed`？**
A：v2.0 有这个问题，原因是缺 27 个前置依赖（Modrinth 上模组本体有 1.21.1 版，但它们的前置没人去查）。
现在有两个解法：

1. **已装 v2.0 的**：跑 `fix_mods.ps1`（在版本目录里），它会补齐 27 个前置 + 删 4 个冲突 + 修 1 个坏 jar
2. **重新导入**：用 v2.1 的 `.mrpack`（226 个模组，依赖闭包已验证）

细节看 `docs/崩溃修复记录.md`。

**Q：日志写 `requires xxx x.y.z or above — Currently, xxx is not installed`？**
A：还有一个前置没补。把 `xxx` 这个 modId 拿到 Modrinth 搜，装它的 1.21.1 NeoForge 版即可。

**Q：日志写 `is incompatible with`？**
A：两个模组互斥。删掉其中一个。v2.1 已经处理掉两对：
`reeses-sodium-options` ↔ `sodium-options-api`（删后者）、
`shoulder-surfing` ↔ `better-third-person`（删后者）。

**Q：日志写 `Missing ModLoader in file` / `not a valid mod file`？**
A：那个 jar 打包有毛病。打开它看 `META-INF/` 下是不是同时有 `neoforge.mods.toml` 和 `mods.toml`，
删掉缺 `modLoader` 字段的那个（通常是 `neoforge.mods.toml`）。

**Q：PCL2 导入 mrpack 卡在下载 0%？**
A：Modrinth 文件 CDN 在你网络下不稳。设置 → 下载 → 下载源切镜像，或开加速重试。
`.mrpack` 里每个文件都有 sha1/sha512，下载完 PCL2 会自动校验，不会装坏。

**Q：启动崩溃，日志里 `Missing or unsupported mandatory dependencies`？**
A：mods 版本不一致。删掉整个 `mods/`，重新用 `.mrpack` 导入一次，别手动增删单个 jar。

**Q：卡在 `KubeJS loading scripts`？**
A：某个脚本语法错。看 `logs/kubejs/server.txt`，最后一行会指出文件名与行号。
本包的脚本都带 try/catch，正常不会卡住；如果你自己改过脚本，用 `//` 注释掉改的那段排查。

**Q：进世界紫黑方块 / 物品没贴图？**
A：`kubejs/assets/godpath/` 没复制过去。把 `manual/kubejs/` 整个覆盖一次。

## 玩法相关

**Q：24 件神物在哪拿？**
A：不在箱子里，是自己做的。挖矿/种地/杀怪掉「法则碎片」，碎片 + 稀有材料合成神物，
tier2 要用同法则的 tier1 当材料。完整表见 `docs/二十四神物图鉴.md`。

**Q：神物丢了会不会前功尽弃？**
A：不会。每次拿到都会被**永久记录**（存玩家 NBT `gp_found`），放进箱子、丢掉、死亡掉落都不影响进度。
只要"曾经拿到过"，成神仪式就认。

**Q：怎么知道还差几件？**
A：右键**星际罗盘**（连接法则），会告诉你还差几件 + 下一件叫什么。
或者看神物拿满时右上角的进度提示。

**Q：磁石在哪？**
A：`下界岩 ×1 + 铁锭 ×8` 合成。放家里当"神座"，24 件齐了右键它。

**Q：成神后能干嘛？**
A：生命 +20、攻击 +6、护甲 +8、移速 +15%、幸运 +5；家园结界 64 格；飞行不需要三叉戟；
拔刀剑进入终局形态；拿到「神格印记」。

**Q：为什么我一开始只有 14 点血？**
A：脆弱期（神物 < 6 件）生命上限 -6。集齐 6 件自动恢复。

**Q：家里为什么真的不刷怪？**
A：你睡过的床 = 家，48 格半径内拦截敌对生物生成（只拦生成，不加任何每 tick 开销）。
换床 = 换结界中心。

**Q：怪物是不是变少了？**
A：没有。结界只覆盖家周围 48 格，野外照常，而且夜间密度不降。

**Q：水桶无限飞怎么触发？**
A：穿鞘翅滑翔 + 背包有水桶 + 有三叉戟，滑翔时自动推进。雨天/水里不带水桶也行。

## 模组与兼容

**Q：为什么没有 Voxy？**
A：Voxy 目前只有 Fabric 构建，1.21.1 没有 NeoForge 版；而 Create 火车只有 NeoForge 版。
两者不可兼得。本包用 **Distant Horizons 3.3.3** 达成同样的"超远视距"目标。

**Q：Terralith 和 Biomes O' Plenty 会打架吗？**
A：可以共存。Terralith 替换/增强原版群系，BOP 追加新群系，Tectonic 改地形高度场。
如果出现"群系错位/地表断层"，优先删 `biomes-o-plenty`（保留 Tectonic + Terralith 更稳）。

**Q：Epic Fight 和 First Person Model 冲突吗？**
A：Epic Fight 会接管第一人称手臂。如果第一人称手臂显示异常，把 `first-person-model` 的
"第一人称手部"选项关掉即可。

**Q：能加光影吗？**
A：能，Iris 已装。但别用重度体积云光影，会吃掉 DH 的帧。

**Q：能再加模组吗？**
A：可以，但别动 `kubejs/`、别改 NeoForge 版本。加之前先看 `docs/模组清单.md` 里有没有重复功能。

## 性能

**Q：多少内存够？**
A：16 GB 机器给 7~8 GB；32 GB 给 10~12 GB。详见 `docs/性能调优.md`。

**Q：为什么远处是"糊的方块"？**
A：那是 DH 的 LOD 远景，走近会逐渐变成真实区块。想要更清晰：提高 DH 的"水平质量"。

**Q：笔记本能玩吗？**
A：能，但要降级：DH 距离 256、关光影、渲染距离 8、粒子 25%。

## 其他

**Q：这个包有任务书吗？**
A：没有，故意的。引导靠三样东西：星际罗盘、原声回响、碎片掉落本身。

**Q：能单人玩吗？**
A：完全可以，所有联机模组单人也正常工作（语音除外）。

**Q：怎么改 24 件的内容？**
A：源数据在 `kubejs/` 之外的 `god_items.json`（打包时在包根），脚本在
`kubejs/server_scripts/`。改完重启服务端即可，客户端不用动。
