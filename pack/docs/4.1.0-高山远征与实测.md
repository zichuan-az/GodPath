# 4.1.0 高山远征

Minecraft 1.21.1 · NeoForge 21.1.250 · Java 21。下载 `.mrpack`，用 PCL2 或兼容 Modrinth 整合包的启动器导入新实例。想从铁路开始，把 `GodPath-Expedition.zip` 里的文件夹解压到该实例的 `saves/`。首次进入时等待车站准备完毕，再输入 `/journey`。普通新建世界也可以使用远征日志。

- **拔刀剑**：修复左键空挥没有连击的问题。普通 Yamato 与神格拔刀剑分别通过了空挥、命中、右键三组验证；每组均由真实游戏按键路径打出 `combo_a1 → combo_a2 → combo_a3 → combo_a4_ex`。持拔刀剑时切换到原版战斗姿态。
- **铁路与成长**：在干净存档中生成云岭枢纽和松脊前哨。普通玩家领到木制刀、命中训练靶三次，搭乘同一辆矿车实际往返。测试夹具在前哨给予世界种子，日志进入阶段 5；工作台手工合成不计入这次实机验证。
- **画面与性能**：整合包内置 CozyUI 中文界面、MakeUp Ultra Fast，加入加宽群系和山脉的 Tectonic 配置。实机单人预热完成 16 个区块；第一次生成铁路与周围地形仍会出现卡顿。实机进程在单人联机内置服务端与光影同时运行时，观察到约 9 GiB 工作集（JVM 堆上限 6 GiB）；这不是最低内存要求或 FPS 承诺。
- **轨道炮（预览）**：主手持炮按 `F7` 切换模式，瞄准已加载的方块，长按右键 3 秒。实机验证了炮身模型、配方注册、开始蓄力以及未成神时禁止开火。已修复瞄准扫描卡住服务端、维度读取和边界检查问题。双模式命中与保护规则还在实机复测。

本版仍保留部分第三方模组的资源与配方警告，未完成多人压力测试或全部 Boss 的回归。保留原有存档备份，建议用独立实例体验。
