# 神格之路 4.0 升级与实测报告

本版使用 Minecraft 1.21.1、NeoForge 21.1.250 和 Java 21，锁定 255 个模组文件。PCL2 导入包包含完整下载清单及覆盖文件。手动安装说明见发行包内的 README。

## 游玩变化

- 六座原创自然遗迹包含守卫、上行路线与对应法则碎片。IDAS、CTOV、MVS、Explorify 和 YUNG 桥梁增加大型地牢、村镇与旅途地标。探索罗盘和自然罗盘用于定位建筑和群系。
- 24 件神物可进入六个 Curios 神物槽。神格印记有独立槽和可见模型。同系两件、四件与六系各一件提供不同共鸣。背包中的神物仍可登记。
- 六系各有三阶原生拔刀剑，共 18 把成长刀。真解与法相配方要求前阶刀达到指定杀敌数、锻造和刀魂，成神额外获得不可损坏的「归墟 · 万象神裁」。原生连段与 SA 仍然可用。本包补充剑气弧线、爆发环形粒子及分阶段仪式效果。
- 成神增加 180 生命、60 攻击、40 护甲、20 韧性、20 幸运、50% 基础移速及抗击退。成神玩家可在生存模式双击跳跃飞行，普通伤害、虚空伤害及标准 `/kill` 由神格防护处理。旧神格的属性会更新，专属刀只发一次。
- 月露透镜读取已加载区块中的遗迹，避免额外进行大范围世界生成搜索。秘法残页为另一只手的装备添加兼容附魔，受原生最高等级和冷却限制。

## 字体、界面与汉化

成神标题使用可翻译文本和独立的 Unicode 字体资源。颜色与粗体通过文本组件设置。Curios 的神物和神格槽名由中文语言资源提供。Overflowing Bars 将成神后的多行生命和护甲压缩成可读的层数显示。

简体中文补充包新增 5,560 条含中文的翻译。所统计的 82,344 个英文键中有 73,082 个含中文对应文本。这是文字覆盖统计，仍有英文条目。CFPA 的来源版本、署名和 CC BY-NC-SA 4.0 许可随包保留。

CozyUI+ v1.10 提供原版和已适配模组的界面。指定的 ysnCE v1.4.0-beta 面向较新的 Minecraft，本版移植了 1.21.1 可用的 HUD 纹理。MakeUp Ultra Fast 9.6 默认使用均衡配置。主菜单背景是为本包制作的插画，遗迹与特效截图来自实机。

## 性能改动

保留 Sodium、Lithium、FerriteCore、ModernFix、Noisium、EntityCulling 和 Clumps 等优化。修正单人导入环境，集成服务器需要的世界生成与优化模组会随客户端安装。新增 FastSuite 和 AllTheLeaks，配方查询使用单一 JEI 索引。

Distant Horizons 默认停用远景渲染与后台生成，普通视距保持 10 区块。此前的远景配置使用 256 区块半径和 10 个后台线程，在测试画面中出现了远景接缝。可在游戏设置中开启远景显示，开启后会增加负载。

单人首次进入主世界会在服务器空闲时自动预热至多 16 个区块。`/gp_pregen start` 手动准备当前位置周围半径 16 区块，`status` 查看进度，`stop` 停止。一次只提交一张临时区块票据，服务器平均刻耗时过高时暂缓提交，完成后释放票据。收益集中在准备范围内，远行至新区块时仍会发生正常生成。


## 验证结果

2026 年 11 月 12 日使用发行包覆盖文件创建干净测试客户端，逐一核对 255 个 jar 的 SHA512。测试使用 Java 21、6 GiB 最大堆和独立的种子 42 存档。正式存档没有参与测试。

| 检查 | 通过 |
|---|---:|
| 核心玩法、手册、附魔与作物 | 17 / 17 |
| 饰品、刀身、成神、飞行与免死 | 9 / 9 |
| 自然结构、奖励表、透镜和配方 | 8 / 8 |
| 中文、字体键、资源包与光影 | 5 / 5 |
| 临时区块票据实际加载 | 1 / 1 |

测试世界中找到自然生成的月露星宫，模板范围为 X 1904–1952、Y 66–113、Z -768–-720。实际存在 Lootr 奖励箱，六张遗迹奖励表均可提供对应碎片。专属刀通过正常使用入口产生剑气并保存了实机截图。客户端解析到「神物」「神格」「神格降临」的完整中文。

上一轮同配置性能测试使用 6 GiB 最大堆。一次采样的 Java 堆使用约 5.51 GiB，进程驻留约 7.57 GiB，进程峰值驻留约 8.16 GiB。堆外资源也会占内存，单次采样不能用作长期内存泄漏或帧率对照结论。

## 已知限制

日志仍记录 36 个第三方配方解析错误，主要集中在未安装的可选联动、物品改名和上游格式差异。三张直接影响现有内容的配方已恢复，包内刀系配方通过游戏验证。长期多人联机、所有 Boss 战和全部维度未逐项实测。

工作区的 `build/verification-4.0/` 保存了结果 JSON、启动日志和实机截图。
