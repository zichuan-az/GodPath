## 四、拔刀剑：四阶 + 两个技能

### 刀阶（击杀累积，永久）

**只算手持拔刀剑时的击杀。**

| 阶 | 需要击杀 | 攻击力 | 攻速 | 额外 |
|---|---|---|---|---|
| 未开锋 | 0 | — | — | 只有基础伤害 |
| **斩击 I** | 25 | +3 | +0.1 | — |
| **斩击 II** | 80 | +6 | +0.2 | — |
| **斩击 III** | 200 | +10 | +0.35 | — |
| **斩击 IV · 刀魂** | 400 | +16 | +0.5 | 击杀触发天雷 |

刀阶存在玩家 NBT 里（`gp_blade_kills` / `gp_blade_tier`），**换维度、重生、死亡都不掉**。

### 技能一　剑气斩（`F8`）

- 冷却 **3 秒**
- 前方 **12 格**穿透，伤害 `6 + 刀阶×4`（刀魂阶 = 22 点）
- 带横扫粒子与音效

### 技能二　刀魂爆发（潜行 + `F8`）

- 冷却 **15 秒**
- 半径 **8 格** AOE，伤害 `10 + 刀阶×6`（刀魂阶 = 34 点）
- 自身获得抗性 IV + 再生 I（3~5 秒）
- **斩断法则 4 件齐**时，额外召唤一道天雷

### 和 24 件神物的联动

| 条件 | 效果 |
|---|---|
| 斩断法则 4 件齐（天雷刀魂/龙牙之刃/虚空刀鞘/终焉铭牌） | 刀魂爆发附带天雷；击杀触发天雷 |
| 持刀 + 斩断齐 | 额外 +12 攻击 / +0.6 攻速（`60_blade.js`） |
| 刀阶 IV + 斩断齐 | 叠满：+16（刀阶）+12（法则）= **+28 攻击** |
| 神格状态 | 再叠 +6，总计 **+34 攻击** |

### 打 Boss 的正确姿势

1. 先把刀阶刷到 III（200 斩，大约 2~3 小时正常游玩）
2. 集齐斩断法则 4 件 → 天雷附伤
3. 潜行时按 `F8` 释放刀魂爆发
4. 松开潜行键，再按 `F8` 释放剑气斩
5. 龙牙之刃在场时，对 Boss 额外制裁

## 五、维度之间的动线建议

```
主世界（Tectonic 史诗地形）
  ├─ 地下 → 更深更暗（远古城市传送门）
  ├─ 下界 → Incendium 地形 → 灾变 BOSS
  ├─ 末地 → Enderscape 浮岛 → 末影龙
  ├─ 蜂巢 → 蜂蜜块 + 末影珍珠
  ├─ 天境 → 萤石框架 + 水桶
  ├─ 永恒星光 → 星辉水晶门
  ├─ 地下花园 → 深地下门
  └─ 星际 → 造火箭
```

**建议顺序**：主世界攒资源 → 天境/蜂巢（低危） → 下界灾变（拿斩断碎片） →
更深更暗（拿幽匿材料） → 末地 → 永恒星光/地下花园 → 星际。

## 六、性能提醒

每多一个维度，**不玩的时候不加载**，所以不会拖慢平时。

但要注意：

| 情况 | 影响 |
|---|---|
| 首次进入新维度 | 生成器初始化，卡 10~30 秒 |
| 同时开 3 个维度传送门 | 内存 +1~2 GB |
| `ad-astra` 火箭发射 | 短时间内大量区块加载 |
| `grimoire-of-gaia` 怪物群 | 实体数暴涨，建议关掉它的"女仆生成" |

低配机建议：先玩主世界 + 天境 + 下界，星际和永恒星光等有空再开。
