# 安装与启动

## 一、PCL2 用户（99% 的人看这里）

### 1. 导入

- 打开 PCL2
- 左边 **版本管理** → 顶部 **导入整合包**
- 选 `神格之路-GodPath-2.0-1.21.1.mrpack`
- 选一个**空文件夹**（不要放在中文路径？PCL2 支持中文，但个别 mod 的日志会乱码，建议纯英文路径）
- 确定 → 等它下载完 203 个模组

### 2. 下载源

PCL2 默认会走 Modrinth 官方 CDN。如果卡住：

- **设置 → 下载 → 下载源**：换成镜像
- 或者开加速工具，重试

### 3. 内存

- 版本设置 → 高级设置 → 内存：**8 GB**（16 GB 机器）
- JVM 参数：把 `docs/性能调优.md` 里那串整行粘进去

### 4. 启动

- 选版本 → 启动
- 第一次进世界会卡 10~30 秒（DH 在算远景），正常
- 进游戏后按 `Esc → 选项 → Distant Horizons`，把 LOD 距离调到 512+

## 二、手动安装（不想用 mrpack）

1. 自己装 **1.21.1 + NeoForge 21.1.250**
2. 跑 `download_mods.ps1`（Windows）→ 会在同目录建 `mods/` 并下 203 个 jar
3. 把 `manual/` 下所有内容复制到游戏根目录：
   ```
   .minecraft/
     ├─ mods/            ← 脚本下好的 203 个
     ├─ kubejs/          ← 从 manual/ 复制（24 神物、飞行、结界、仪式）
     ├─ config/          ← 从 manual/ 复制
     └─ docs/            ← 说明书
   ```
4. 启动

> 关键：`kubejs/` 里不只有脚本，还有 24 件神物的**贴图与语言文件**。
> 不复制会变成紫黑方块。

## 四、第一次进游戏的 5 件事

1. **睡一张床** → 建立家园结界（48 格不刷怪）
2. **找铁轨拆几节** → 连接碎片（12%）
3. **挖深板岩** → 原初碎片（3.5%）
4. **合成星际罗盘** → 它会告诉你下一步该找什么
5. **按 O 圈一块地** → 防拆家（联机时必做）

## 五、按键速查

| 键 | 功能 | 来自 |
|---|---|---|
| `V` | 语音说话 | Simple Voice Chat |
| `O` | 领地/队伍 | Open Parties and Claims |
| `J` | 小地图设置 | Xaero's Minimap |
| `M` | 世界地图 | Xaero's World Map |
| `H` | Distant Horizons 设置 | DH |
| `R` | 物品配方查询 | JEI |
| `Ctrl` | 疾跑（Epic Fight 改过） | 原版 |
| `Shift` | 潜行（神物记录坐标用） | 原版 |

## 六、卸载/回滚

- mrpack 导入的实例：PCL2 里直接删版本文件夹
- 玩家进度：`saves/<世界>/playerdata/*.dat` 里存着 `gp_found`（神物记录），备份这个就能带走进度
