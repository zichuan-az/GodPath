# 神格之路 4.0.1 · 拔刀剑与饰品修复

## 修复内容

- 本地 F2 截图 `2026-11-12_15.58.46.png` 里的紫黑格来自空槽贴图。旧 ID `curios:slot/empty_curios_slot` 在 Curios 9.5.1 中找不到资源。神物槽和神格槽改用该版本实装的 `empty_charm_slot` 和 `empty_curio_slot`。
- 普通右键以前会同时触发本包剑气，潜行右键会同时触发刀魂爆发。两招改由独立技能键发起，服务端按实际主手、潜行状态与冷却判定。默认 `F8` 施放剑气斩，潜行时按 `F8` 施放刀魂爆发。
- 分离技能后，实测发现 Spell Engine 仍会给拔刀剑自动分配武器技能。对拔刀剑的五种原生物品追加自动分配排除标签，覆盖原版名刀和本包使用同一物品 ID 的成长刀与神裁。其他武器继续按各自的法术分配规则处理。[Spell Engine 1.21.1 的自动分配说明](https://github.com/ZsoltMolnarrr/SpellEngine/blob/1.21.1/README.md#fallback-assignment)
- 主手持有原生拔刀剑时，客户端将 Epic Fight 切回原版模式，即使玩家进存档时已经持刀。换用其他武器后，可以按 Epic Fight 原有按键切换战斗模式。
- 移除第三人称动画模组 Not Enough Animations。254 个模组仍使用固定版本。4.0 的存档可复制到新的 4.0.1 实例继续使用。

## 实机回归

使用 Minecraft 1.21.1、NeoForge 21.1.250、Java 21 和 254 个锁定模组，在隔离客户端打开已有的 4.0 单人测试存档。客户端回放实际攻击和使用键位。以下是服务端记录的原生起招阶段，省略收招和空闲状态。

| 刀身 | 左键 | 右键 |
|---|---|---|
| 原生大太刀 | A1 → A2 → A3 | A1 → A3 → A4 EX |
| 归墟 · 万象神裁 | A1 → A2 → A3 → A4 EX | A1 → A3 → A4 EX |

- 测试开启 Epic Fight 战斗模式后，持刀时恢复原版模式。两把拔刀剑均无 Spell Engine 自动武器技能，同实例的铁剑仍有。
- 所有鼠标回放结束后，测试通过独立客户端通道触发剑气和潜行爆发，分别观察到各自的冷却。客户端检查到 `F8` 只有本包技能绑定。这里验证了键位注册和实际技能通道，未用实体键盘按下 `F8`。
- 实际打开 Curios 界面，两类空槽的图集资源均有效。截图显示六个空神物槽与一个空神格槽，另有神裁原生右键白色挥刀弧和独立剑气粒子截图。
- 32 项脚本测试、16 项数据与发行检查。原生蓄力动作继续由拔刀剑处理，本轮重点回放普通左键、右键和连段。

工作区的实测日志和截图位于 `build/verification-4.0.1/`。
