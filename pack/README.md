# 神格之路 GodPath 4.1 · 高山远征

Minecraft 1.21.1 · NeoForge 21.1.250 · Java 21 · 254 个锁定模组

前期求生，逐渐发展科技、铁路、魔法与庄园；通过探索、挖矿、收获和战斗取得碎片，集齐六法则的 24 件神物，在磁石前完成成神仪式。首次进入会获得中文远行手册，没有强制任务链。

## 安装

在 PCL2 中导入 4.1 `.mrpack`，选择一个新的独立版本目录。启动器根据清单下载并校验模组。

想从铁路开局：解压 `GodPath-Expedition.zip`，把其中的 `GodPath-Expedition` 文件夹放进新实例的 `saves/`。进入「神格之路 · 高山远征」后，等候双站和铁路准备完毕。输入 `/journey`，在云岭枢纽领木制拔刀剑，练刀后原路搭矿车远征。也可直接新建普通世界，`/journey` 仍提供玩法提示。

手动安装：先创建 Minecraft 1.21.1 + NeoForge 21.1.250 版本，把 `manual-overrides/` 的内容复制到该版本的游戏目录，再在该目录运行 `download_mods.ps1`（Windows）或 `bash download_mods.sh`。下载器与 `mods.json` 必须放在一起。

16 GB 机器以 6 GB Java 堆作为起点。使用 ]ava 21，不要附加不支持的 `UseCompactObjectHeaders` 参数。首次启动需要建立大量模组配方和资源索引，耗时明显长于后续启动。

## 本版新增

- 4.0.2 修复 Garnished 染色、Malum 灵魂修理和睡眠烟雾弹配方，恢复缺少 Wares 时的 CTOV 仓库纸张战利品。成神仪式重新开始时重新计时，首次区块预热中断后可在下次进入重试。复测见 `docs/4.0.2-深度回归报告.md`。
- 模组中文补充包、CozyUI+ v1.10 与 ysnCE 的 1.21.1 兼容适配；默认启用简体中文。
- 原创晨曦遗迹主菜单与中文导航；MakeUp Ultra Fast 9.6 均衡光影默认启用。
- IDAS、CTOV、MVS、Explorify、YUNG 桥梁，增加地牢、村镇、地标与旅途景观。
- 六座原创自然法则遗迹，高层宝箱提供对应碎片与旅行补给，将探索接入主线。
- Lootr、探索者罗盘、自然罗盘与中文远行手册。

新建筑需要新生成区块，推荐新建世界。配置、资源包顺序、性能预设与许可见 `docs/大世界探索与画质.md`。本包保留部分模组的未译文本，汉化统计见 4.0 报告。

## 神格和刀系

24 件神物可以装备在六个 Curios 神物槽，神格印记有专属槽。同系两件、四件与六系各一件有不同增益。成神后免疫普通伤害、虚空伤害和标准 `/kill`，双击跳跃进入自由飞行。

18 把成长刀分属六条法则路线。按刀身杀敌数、锻造和刀魂提高阶位，配方可在 JEI 查阅。成神获得专属「归墟 · 万象神裁」，详细数值见 `docs/六道刀谱与饰品共鸣.md`。

4.0.1 修复空神物槽和空神格槽的贴图。拔刀剑空挥也会进入原生连击。命中、右键与蓄力继续沿用原模组。整合包技能默认使用 `F8`，潜行时按 `F8` 切换为刀魂爆发。拿起拔刀剑时 Epic Fight 会切至原版模式。拔刀剑也跳过 Spell Engine 的自动武器技能分配。

## 成长路线

- 六种碎片均有合成保底；神物配方可在 JEI 查阅。
- 原初：深板岩、凝灰岩、远古残骸；机械：铁矿、铜矿。
- 连接：铁轨；奥秘：紫水晶；丰饶：成熟作物；斩断：敌对生物。
- 支持名单中的 Boss 固定掉落斩断碎片 ×4 和奥秘碎片 ×1；普通怪维持原掉率。
- 神物进入背包后每秒扫描登记，登记过的神物可以存入箱子；二阶配方会消耗同系一阶材料，先确认共鸣提示。
- 星际罗盘显示缺少的神物线索。集齐 24 件后右键磁石，等待 13 秒；退出或死亡会取消进行中的仪式，可重进后重试。

## 本轮验证的关键行为

- 普通、非 OP 玩家可以使用神物效果。
- 世界种子和共振信标同时记录坐标与维度；旧存档的坐标没有维度信息，重新记录一次即可。
- 四季之心与沃土之印只催熟周围支持的作物，不修改全服随机刻速度。
- 拔刀剑有 25 / 80 / 200 / 400 斩四阶；收起武器后卸除刀阶属性，再装备会恢复。
- 剑气斩和虚空斩作用于前方敌人；爆发逐个结算周围敌人的伤害。
- 成神永久增加 180 生命、60 攻击、40 护甲、20 韧性、20 幸运与 50% 基础移速，并提供抗击退、不死与生存飞行。
- 神格属性丢失后会重新应用，恢复过程不会重复赠送成神奖励。
- 家园结界基于床的重生点，通常半径 48 格，神格 64 格。
- 鞘翅滑翔时，背包里的水桶和三叉戟可用于自动推进；雨水环境可替代水桶，灵风之杖和神格提供替代条件及推进加成。

## 从旧包更新

推荐新建版本导入修复版后，再自行备份、迁移存档。不要把整个旧 `mods/` 覆盖到修复版，否则会把已排除的冲突重新装回去。

4.0.1 移除了「更多动画」Not Enough Animations。若在现有 4.0 实例手动更新，移出 `mods/notenoughanimations-neoforge-1.12.6-mc1.21.1.jar`，再应用 4.0.1 覆盖文件。

Structory Towers 锁定为元数据正常的 1.0.15 原版；Iris 改为支持 Sodium 0.8 的 1.8.14-beta.1。旧版 Iris、旧版 Towers 与修复版不能并存。

## 轨道炮

成神后才可发射。用 JEI 查看合成配方，主手持炮，按 `F7` 切换，瞄准已载入的实心方块，持续按右键 3 秒。每次发射共享 30 秒冷却。

- 生物歼灭：对落点周围半径 24 格内的生物造成伤害，不拆方块；玩家、驯养动物和不允许进入的领地受保护。
- 地形轰击：生成半径 16 格、最深 24 格的漏斗形弹坑，分批移除方块且不掉落物品。铁路保护区、已认领区块、容器和基岩会保留。
